# dsh-locale-ru

Русский язык для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

Интерфейс DeepSeek Harness выходит на английском и упрощённом китайском. Этот плагин добавляет русский третьим выбираемым языком и переводит всю клиентскую часть: **2444 строки в 58 пространствах имён**.

## Что даёт пакет

- **«Русский» в списке языков.** Появляется в *Настройки → Общие → Язык* рядом со встроенными языками, переключение применяется сразу, без перезагрузки страницы.
- **Полное покрытие клиентского интерфейса.** Чат и подписи о ходе работы агента, траектория, все разделы настроек, рабочая область и боковая панель, фоновые задачи, результаты, планы и цели, менеджер плагинов, субагенты и команды агентов, голосовой ввод, горячие клавиши, просмотр документов, диалоги.
- **Выбор сохраняется.** Предпочтение хранит хост-часть, поэтому оно переживает перезапуск. Пока ничего не сохранено, язык берётся из списка языков браузера.
- **Частичный перевод безопасен.** Поиск идёт по цепочке `ru → en`, поэтому непереведённый ключ покажет английский текст, а не имя ключа.
- **Внутри DSH ничего не меняется.** Пакет — обычный клиентский плагин профиля, поэтому обновления DSH его не затирают, а удаление сводится к одной команде.

## Требования

- DeepSeek Harness с настольным или веб-интерфейсом. Собрано и проверено на `0.2.0-rc.2`.
- Профиль, в который можно ставить плагины. Настольное приложение кладёт CLI по пути
  `%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd` — добавьте этот каталог в `PATH` или вызывайте файл напрямую.

## Установка

```powershell
# прямо из репозитория
dsh plugin --profile desktop add https://github.com/xISPx/dsh-locale-ru

# или из локальной копии
git clone https://github.com/xISPx/dsh-locale-ru
dsh plugin --profile desktop add ./dsh-locale-ru
```

Обновите страницу GUI, откройте *Настройки → Общие → Язык* и выберите **Русский**. Профиль пересобирается работающим приложением; если пункт не появился — перезапустите DSH.

Удаление:

```powershell
dsh plugin --profile desktop remove dsh-locale-ru
```

## Как это устроено

DSH локализует интерфейс через клиентский сервис `@deepseek-ai/dsh-client-locale`. Каждый клиентский плагин регистрирует свои словари для встроенных языков:

```js
ctx.locale.register('chat', { zh, en })
```

Сторонний клиентский плагин может добавить язык и словари для любых пространств имён:

```js
ctx.locale.addLanguage({ id: 'ru', label: 'Русский', fallback: 'en' })
ctx.locale.register('chat', 'ru', { /* ключ: перевод */ })
```

Поиск ключа идёт по цепочке отката активного языка, повторяясь в пространстве имён `common`, и лишь затем показывается сам ключ. Именно эта цепочка делает частичный перевод безопасным — и поэтому пакету достаточно присылать только русскую половину каждого словаря.

Этот репозиторий и есть такой плагин. `cordis.patch.yml` объявляет одну строку загрузчика, `lib/index.js` — пустая хостовая половина (пакет работает только в браузере), а `lib/client.js` — браузерный бандл, регистрирующий язык и словари.

## Разработка

Подойдёт любой Node.js 18+; в установке DSH есть свой —
`%USERPROFILE%\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe`.

```powershell
node tools/check-ru.mjs --merged     # структура: ключи, плейсхолдеры, пробелы
node tools/lint-ru.mjs               # терминология и стиль
node build.mjs                       # locales/ru.json -> lib/client.js
node tools/selftest.mjs              # проверка собранного бандла
```

`build.mjs --check` проверяет без записи и сообщает как о непереведённых ключах, так и о переводах, потерявших `{плейсхолдер}`.

### После обновления DSH

Английские строки живут внутри клиентских бандлов DSH, поэтому новая версия может добавить, переименовать или убрать ключи:

```powershell
powershell -ExecutionPolicy Bypass -File tools\extract-bundles.ps1 -Dest "$env:TEMP\dsh-bundles"
node tools\extract-english.mjs "$env:TEMP\dsh-bundles" --write
node build.mjs --check
```

Дальше остаётся перевести то, что покажет `--check`, и пересобрать бандл.

> Скрипт сохранён в UTF-8 **с BOM**: Windows PowerShell 5.1 иначе читает кириллицу как ANSI и не разбирает файл. При правке BOM нужно сохранить.

### Про перезагрузку

DSH публикует бандл клиентского плагина один раз, при загрузке конфигурации, а метку версии вычисляет по времени изменения файла и его размеру. Поэтому правка `lib/client.js` на диске сама по себе до работающего приложения не доходит — перезапустите DSH или переустановите пакет, чтобы он опубликовался заново:

```powershell
dsh plugin --profile desktop remove dsh-locale-ru
dsh plugin --profile desktop add ./dsh-locale-ru
```

## Как участвовать

Переводы — это обычный JSON, поэтому правка обычно состоит из одной строки в `locales/ru.json` и запуска `build.mjs`. Сначала прочитайте [TRANSLATION.md](TRANSLATION.md): там глоссарий (session → «сессия», workspace → «рабочая область», subagent → «субагент», …) и два правила, которые легко нарушить:

- **Плейсхолдеры и краевые пробелы буквальны.** `{count}` должен остаться без изменений, а строка, начинающаяся или заканчивающаяся пробелом, сохраняет его: такие фрагменты склеиваются с соседними.
- **Для множественного числа есть только `*.one` и `*.other`.** Рантайм выбирает `*.one` ровно для единицы и `*.other` во всех остальных случаях, поэтому `*.other` формулируется без согласования с числительным — «Запущено субагентов: {count}» одинаково верно для 2, 5 и 21.

## Ограничения

- **Только текст из словарей.** Строки, которые DSH берёт не из реестра локализации, остаются английскими: вывод CLI, описания пакетов плагинов, диагностика pnpm и загрузчика.
- **Часть текста фиксируется при регистрации.** Некоторые подписи, например описания команд, сохраняют язык, под которым были зарегистрированы, до пересборки дерева плагинов; текст, отрисовываемый слотами, следует за переключением сразу.
- **Нет правил множественного числа и двунаправленной вёрстки.** Сервис локализации даёт только выбор языка, его сохранение, сопоставление с языком браузера, откат по ключам и `<html lang>`.
- **Служебные окна Electron не покрыты.** Окна приветствия и обновления — статический HTML внутри `app.asar`, вне системы локализации.
